# 栈与队

## 栈

### 定义

栈是限定在线性表一端进行插入和删除的特殊线性表。

### 特点

- 元素间呈线性关系
- 插入删除只在一端进行
- 后进先出，先进后出
- `LIFO`（Last-In-First-Out）

### 基本操作

- `push`：进栈
- `pop`：出栈
- `isEmpty`
- `isFull`
- `getTop`

### 顺序栈

#### 构造原理

课件用一维数组 `STACK[0..M-1]` 表示顺序栈，并用整型变量 `Top` 给出栈顶元素的位置。

初始时：

```c
#define MAXSIZE 1000
ElemType STACK[MAXSIZE];
int Top;
```

并约定：

$$
Top = -1
$$

#### 判空与判满

```c
int isEmpty() { return Top == -1; }

int isFull() { return Top == MAXSIZE - 1; }
```

#### 进栈

```c
void push(ElemType s[], ElemType item) {
    if (isFull()) Error("Full Stack!");
    else s[++Top] = item;
}
```

#### 出栈

```c
ElemType pop(ElemType s[]) {
    if (isEmpty()) Error("Empty Stack!");
    else return s[Top--];
}
```

### 链栈

构造思想：

- 用线性链表实现栈
- `Top` 指向当前栈顶结点
- 栈空时 $Top = NULL$

链栈的关键结论：

- 进栈相当于在链表头插入结点
- 出栈相当于删除链表头结点
- 一般不需要判“栈满”，但要处理申请结点失败

## 表达式求值

### 中缀转后缀规则

课件给出的规则：

1. 从左到右遍历中缀表达式中每个数字和符号。
2. 若是数字，直接输出。
3. 若是 $)$，则将栈中元素弹出并输出，直到遇到 $($，$($ 弹出但不输出。
4. 若是 $($、$+$、$*$ 等符号，则从栈中弹出并输出优先级高于当前符号的运算符，直到遇到优先级低的符号，然后将当前符号压栈。
5. 遍历结束，将栈中所有元素依次弹出。

### 后缀表达式求值规则

1. 从左到右遍历后缀表达式。
2. 若是数字，直接进栈。
3. 若是运算符，则弹出两个元素计算，结果再入栈。
4. 遍历结束，栈中应只剩一个结果。

### 课件结论

- 前序、中序、后序这些“结构化递归过程”常和栈思想对应。
- 编译器中常先把中缀表达式转成后缀表达式，再做计算或生成代码。

## 队列

### 定义

队列是限定在线性表一端插入、另一端删除的特殊线性表。

### 特点

- 先进先出
- `FIFO`（First-In-First-Out）

### 基本操作

- `enQueue`：入队
- `deQueue`：出队
- `isEmpty`
- `isFull`
- 取队头元素
- 创建空队

## 循环队列

### 构造原理

课件采用：

- `Front`：队头位置
- `Rear`：队尾位置
- `Count`：当前队中元素个数

```c
#define MAXSIZE 1000
QElemType QUEUE[MAXSIZE];
int Front, Rear, Count;
```

初始值：

```c
Front = 0;
Rear = MAXSIZE - 1;
Count = 0;
```

### 判空与判满

```c
int isEmpty() { return Count == 0; }

int isFull() { return Count == MAXSIZE; }
```

### 入队

```c
void enQueue(ElemType queue[], ElemType item) {
    if (isFull()) Error("Full queue!");
    else {
        Rear = (Rear + 1) % MAXSIZE;
        queue[Rear] = item;
        Count++;
    }
}
```

### 出队

```c
ElemType deQueue(ElemType queue[]) {
    ElemType e;
    if (isEmpty()) Error("Empty queue!");
    else {
        e = queue[Front];
        Count--;
        Front = (Front + 1) % MAXSIZE;
        return e;
    }
}
```

## 链队

### 构造思想

- `Front` 指向队头结点
- `Rear` 指向队尾结点
- 空队时 $Front = NULL$

### 入队

```c
void enLQueue(ElemType item) {
    QNodeptr p;
    if ((p = (QNodeptr)malloc(sizeof(QNode))) == NULL) Error("No memory!");
    p->data = item;
    p->link = NULL;
    if (Front == NULL) Front = p;
    else Rear->link = p;
    Rear = p;
}
```

### 出队

```c
ElemType deLQueue() {
    QNodeptr p;
    ElemType item;
    if (isEmpty()) Error("Empty queue!");
    else {
        p = Front;
        Front = Front->link;
        item = p->data;
        free(p);
        return item;
    }
}
```

## 本章应记住的结论

- 栈：`LIFO`，只在一端插删。
- 队：`FIFO`，一端插入、一端删除。
- 循环队列是顺序队列的常用实现，目的是复用数组前部空间。
- 表达式求值是栈的经典应用。
- 银行排队、生产者-消费者模型是队列的典型应用。
