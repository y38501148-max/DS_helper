# 图

## 图的基本概念

### 定义

图可表示为 $G=(V,E)$：

- `V`：顶点的非空有穷集合
- `E`：边（或弧）的集合

### 分类

- 无向图：若 $(v_i, v_j)\in E$，则 $(v_j, v_i)\in E$，且顶点顺序无关。
- 有向图：若 $\langle v_i, v_j\rangle\in E$，则顶点顺序有关。
- 网络：边上带权的图。

## 常用术语

### 顶点的度

- 无向图：依附于顶点 `vi` 的边数为该顶点的度。
- 有向图：
  - 出度 $OD(v_i)$：以 $v_i$ 为出发点的边数
  - 入度 $ID(v_i)$：以 $v_i$ 为终止点的边数
  - 总度 $TD(v_i) = OD(v_i) + ID(v_i)$

### 重要结论

课件中的三个结论：

1. 具有 $n$ 个顶点的有向图最多有 $n(n-1)$ 条边。
2. 具有 $n$ 个顶点的无向图最多有 $n(n-1)/2$ 条边。
3. 对于具有 `n` 个顶点、`e` 条边的图：

   $e = \frac{1}{2}\sum TD(v_i)$（无向图）

### 路径与回路

- 路径：顶点间存在一条由相邻边连接起来的顶点序列。
- 回路（环）：出发点和终止点相同的路径。
- 简单路径：顶点序列中顶点不重复出现的路径。
- 不带权图路径长度：边数。
- 带权图路径长度：边权之和。

### 连通

- 无向图中任意两点连通，则为连通图。
- 有向图中任意两点互相可达，则为强连通图。
- 极大连通子图称连通分量。
- 极大强连通子图称强连通分量。

## 生成树与最小生成树

### 生成树

> 包含具有 `n` 个顶点的连通图全部 `n` 个顶点，仅包含其 `n-1` 条边的极小连通子图称为该图的一个生成树。

### 生成树性质

包含 `n` 个顶点的图满足以下等价关系：

- 连通且有 `n-1` 条边
- 无回路且有 `n-1` 条边
- 无回路且连通
- 是一棵树

### 最小生成树

> 带权连通图中，总权值之和最小的生成树称为最小生成树。

### 基本原则

- 只能利用图中的边
- 只能选 `n-1` 条边连接 `n` 个顶点
- 不能产生回路

## 图的存储

### 邻接矩阵

核心思想：

- 一维数组存顶点信息
- 二维数组存边关系信息

性质：

1. 无向图的邻接矩阵一定是对称矩阵。
2. 无向图邻接矩阵第 `i` 行（列）非零或非 `∞` 元素个数为顶点度数。
3. 有向图第 `i` 行非零元素个数为出度，第 `i` 列非零元素个数为入度。

空间复杂度：

$$
O(n^2)
$$

### 邻接表

核心思想：

- 每个顶点一个头结点
- 以链表方式挂接从该顶点出发的边

性质：

1. 无向图第 `i` 个链表边结点个数是该顶点度数。
2. 有向图第 `i` 个链表边结点个数是该顶点出度。

典型定义：

```c
typedef struct edge {
    int adjvex;
    int weight;
    struct edge *next;
} ELink;

typedef struct ver {
    vertype vertex;
    ELink *link;
} VLink;
```

## 图的遍历

### 定义

> 从图中某个指定顶点出发，按照某一原则对图中所有顶点都访问一次，得到一个由图中所有顶点组成的序列，这一过程称为图的遍历。

## 深度优先遍历 DFS

### 原则

从某顶点出发，先访问该顶点，再从其未访问过的一个邻接点出发继续深度优先遍历，直到当前连通分量访问完，再处理其他未访问顶点。

### 访问标记

```c
int Visited[N] = {0};
```

### 课件算法

```c
void travelDFS(VLink G[], int n) {
    int i;
    for (i = 0; i < n; i++) Visited[i] = 0;
    for (i = 0; i < n; i++)
        if (!Visited[i]) DFS(G, i);
}

void DFS(VLink G[], int v) {
    ELink *p;
    Visited[v] = 1;
    VISIT(G, v);
    for (p = G[v].link; p != NULL; p = p->next)
        if (!Visited[p->adjvex]) DFS(G, p->adjvex);
}
```

### 复杂度

- 邻接表：$O(n + e)$
- 邻接矩阵：$O(n^2)$

## 广度优先遍历 BFS

### 原则

从某顶点出发，先访问该顶点，再依次访问其所有未访问过的邻接点，然后再按同样规则访问这些邻接点的邻接点。

### 课件算法

```c
void travelBFS(VLink G[], int n) {
    int i;
    for (i = 0; i < n; i++) Visited[i] = 0;
    for (i = 0; i < n; i++)
        if (!Visited[i]) BFS(G, i);
}

void BFS(VLink G[], int v) {
    ELink *p;
    Visited[v] = 1;
    enQueue(Q, v);
    while (!emptyQ(Q)) {
        v = deQueue(Q);
        VISIT(G, v);
        for (p = G[v].link; p != NULL; p = p->next) {
            if (!Visited[p->adjvex]) {
                Visited[p->adjvex] = 1;
                enQueue(Q, p->adjvex);
            }
        }
    }
}
```

### DFS 与 BFS

课件结论：

- 两者时间复杂度相同，本质区别是访问顺序不同。
- DFS 更适合目标较明确、以“找到目标”为主的情况。
- BFS 更适合逐层扩展、寻找相对最优解的情况。

## 最小生成树

### Prim 算法思想

从一个初始顶点开始，每次选择一条连接“已选顶点集合”和“未选顶点集合”的最小权边加入生成树。

### 课件代码

```c
#define MAXVER 512
#define INFINITY 32767

void Prim(int weights[][MAXVER], int n, int src, int edges[]) {
    int minweight[MAXVER], min;
    int i, j, k;

    for (i = 0; i < n; i++) {
        minweight[i] = weights[src][i];
        edges[i] = src;
    }
    minweight[src] = 0;

    for (i = 1; i < n; i++) {
        min = INFINITY;
        for (j = 0, k = 0; j < n; j++) {
            if (minweight[j] != 0 && minweight[j] < min) {
                min = minweight[j];
                k = j;
            }
        }
        minweight[k] = 0;
        for (j = 0; j < n; j++) {
            if (minweight[j] != 0 && weights[k][j] < minweight[j]) {
                minweight[j] = weights[k][j];
                edges[j] = k;
            }
        }
    }
}
```

### Kruskal 算法思想

每次选择当前未选择过的最小权边；若加入后不成环，则保留，否则舍弃；直到选出 `n-1` 条边。

### 课件结论

- Kruskal 适合稀疏图。
- Prim 对稠密图更有利。
- 两者本质上都是贪婪算法。

## 最短路径

### 路径长度

- 不带权图：路径上边的数目。
- 带权图：路径上边权值之和。

## Dijkstra 算法

### 适用问题

- 单源点最短路径
- 图采用邻接矩阵存储
- 边权不能为负

### 核心思想

- 维护源点到各点的当前最短权值数组 `Sweight`
- 每次选出一个尚未确定、但当前距离最小的顶点
- 用它去松弛其他顶点

### 课件代码

```c
void Dijkstra(int v0) {
    int i, j, v, minweight;
    char wfound[VNUM] = {0};

    for (i = 0; i < VNUM; i++) {
        Sweight[i] = Weights[v0][i];
        Spath[i] = v0;
    }
    Sweight[v0] = 0;
    wfound[v0] = 1;

    for (i = 0; i < VNUM - 1; i++) {
        minweight = INFINITY;
        for (j = 0; j < VNUM; j++) {
            if (!wfound[j] && Sweight[j] < minweight) {
                v = j;
                minweight = Sweight[v];
            }
        }
        wfound[v] = 1;
        for (j = 0; j < VNUM; j++) {
            if (!wfound[j] && minweight + Weights[v][j] < Sweight[j]) {
                Sweight[j] = minweight + Weights[v][j];
                Spath[j] = v;
            }
        }
    }
}
```

### 需要记住的限制

- Dijkstra 不适用于含负权边的图。
- 若存在负回路，最短路径问题将失去通常意义。

## 本章应记住的结论

- 邻接矩阵适合稠密图，邻接表适合稀疏图。
- DFS 与 BFS 都必须配合访问标记数组。
- 最小生成树解决的是“总权最小”，不是“某源点到各点路径最短”。
- Dijkstra 是单源最短路径算法，且要求无负权边。
