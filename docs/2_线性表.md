# 线性表

## 线性表的定义

> 数据元素之间具有线性关系的数据元素集合称为线性表，数据元素的个数 `n` 为线性表的长度，长度为 `0` 的线性表称为空表。

### 特点

- 同一性
- 有穷性
- 有序性

## 线性表的基本操作

课件列出的基本操作：

1. 创建一个新的线性表
2. 求线性表长度
3. 检索第 `i` 个数据元素
4. 按关键字查找数据元素的位置
5. 在线性表第 `i` 个位置存入新元素
6. 在线性表第 `i` 个位置插入新元素
7. 删除第 `i` 个数据元素
8. 排序
9. 销毁
10. 复制
11. 合并
12. 分解

## 顺序存储结构

### 构造原理

> 用一组地址连续的存储单元依次存储线性表的数据元素，数据元素之间的逻辑关系通过数据元素的存储位置直接反映。

若每个数据元素占用 $k$ 个存储单元，已知第一个元素地址 $LOC(a_1)$，则：

$$
LOC(a_i) = LOC(a_1) + (i - 1)k
$$

### 结论

这一公式说明：顺序表支持按位置随机访问。

### 顺序表表示

```c
#define MaxSize 100
ElemType A[MaxSize];
int n;
```

其中：

- `MaxSize` 为预先分配空间
- `n` 为表长

## 顺序表的查找

### 顺序查找

```c
int searchElem(ElemType list[], int n, ElemType item) {
    int i;
    for (i = 0; i < n; i++) {
        if (list[i] == item) {
            return i; /* 查找成功 */
        }
    }
    return -1; /* 查找失败 */
}
```

时间复杂度：$O(n)$

### 折半查找

适用前提：有序顺序表。

核心思想：

- 与中间元素比较
- 小于则查前半部分
- 大于则查后半部分
- 相等则成功
- $low > high$ 时失败

```c
int searchElem(ElemType list[], int n, ElemType item) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (high + low) / 2;
        if (item < list[mid]) high = mid - 1;
        else {
            if (item > list[mid]) low = mid + 1;
            else return mid;
        }
    }
    return -1;
}
```

时间复杂度：$O(\log_2 n)$

课件中的直观结论：

- 若顺序表有 `1024` 个元素，顺序查找平均约需 `512` 次比较；
- 折半查找最多只需 `10` 次。

### 用折半查找确定插入位置

```c
int searchElem(ElemType list[], ElemType item) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (high + low) / 2;
        if (item < list[mid]) high = mid - 1;
        else {
            if (item > list[mid]) low = mid + 1;
            else return mid;
        }
    }
    return low;
}
```

当查找失败时，返回值 `low` 就是插入位置。

## 链式存储结构

### 定义

> 线性链表是一种非连续存储结构。

链表中每个结点通常包括：

- 数据域
- 指针域

### 典型特点

- 插入、删除不需要大量移动元素
- 不能像顺序表那样随机访问
- 查找、定位等操作通常需要顺序遍历

### 结论

课件总结：

> 若线性表需要频繁查找、较少进行插入和删除，宜采用顺序存储结构。  
> 若需要频繁插入和删除，宜采用链表结构。

## 字符串作为线性表应用

课件把主串与子串查找也放在线性表应用中处理：

- 主串：源串
- 子串：目标串

朴素匹配算法时间复杂度仍为 $O(nm)$。

## 本章应记住的结论

- 线性表的逻辑特征是“一对一”的线性关系。
- 顺序表最大的优势是可随机访问。
- 折半查找只适用于有序顺序表。
- 链表插删方便，查找较慢。
- 存储结构选型要和操作特征匹配。
