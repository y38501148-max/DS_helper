# 排序

## 排序的基本概念

### 定义

> 对于含有 `n` 个记录的序列 `{R1, R2, ..., Rn}`，对应关键字序列 `{k1, k2, ..., kn}`，确定一种置换关系，使得关键字满足非降序或非升序，相应文件成为按关键字有序的文件，这一过程称为排序。

更直接地说：

> 将一个按值任意的数据元素序列转换为一个按值有序的数据元素序列。

### 排序的功能

- 把无序数据变成有序数据
- 提高查找效率

### 分类

- 内排序：数据能一次全部装入内存
- 外排序：数据太大，排序时需要内外存交换

## 排序性能评价

### 三个维度

1. 时间性能
2. 空间性能
3. 稳定性

### 稳定性定义

> 对于值相同的两个元素，排序前后的先后次序不变，则称该方法是稳定排序；否则是不稳定排序。

## 插入排序

### 核心思想

第 $i$ 趟把第 $i+1$ 个元素插入到前面已经有序的长度为 $i$ 的子序列中的合适位置。

### 算法

```c
void insertSort(keytype k[], int n) {
    int i, j;
    keytype temp;
    for (i = 1; i < n; i++) {
        temp = k[i];
        for (j = i - 1; j >= 0 && temp < k[j]; j--) k[j + 1] = k[j];
        k[j + 1] = temp;
    }
}
```

### 结论

- 最好情况：$O(n)$
- 最坏情况：$O(n^2)$
- 平均情况：$O(n^2)$
- 空间复杂度：$O(1)$
- 稳定

### 折半插入排序

课件用折半查找先找插入位置，再整体后移：

```c
void insertBSort(keytype k[], int n) {
    int i, j, low, high, mid;
    keytype temp;
    for (i = 1; i < n; i++) {
        temp = k[i];
        low = 0;
        high = i - 1;
        while (low <= high) {
            mid = (low + high) / 2;
            if (temp < k[mid]) high = mid - 1;
            else low = mid + 1;
        }
        for (j = i - 1; j >= low; j--) k[j + 1] = k[j];
        k[low] = temp;
    }
}
```

注意：减少的是比较次数，不减少移动次数。

## 选择排序

### 核心思想

每一趟从未排好序的元素中选出最小值，放到当前未排序区间最前面。

### 算法

```c
void selectSort(keytype k[], int n) {
    int i, j, d;
    keytype temp;
    for (i = 0; i < n - 1; i++) {
        d = i;
        for (j = i + 1; j < n; j++)
            if (k[j] < k[d]) d = j;
        if (d != i) {
            temp = k[d];
            k[d] = k[i];
            k[i] = temp;
        }
    }
}
```

### 结论

- 比较次数与原始序列状态无关
- 时间复杂度：$O(n^2)$
- 空间复杂度：$O(1)$
- 不稳定

## 冒泡排序

### 核心思想

每一趟对前 $n-i+1$ 个元素，从前往后比较相邻元素，若前者大于后者则交换，使本趟最大值“沉”到末尾。

### 算法

```c
void bubbleSort(keytype k[], int n) {
    int i, j, flag = 1;
    keytype temp;
    for (i = n - 1; i > 0 && flag == 1; i--) {
        flag = 0;
        for (j = 0; j < i; j++) {
            if (k[j] > k[j + 1]) {
                temp = k[j];
                k[j] = k[j + 1];
                k[j + 1] = temp;
                flag = 1;
            }
        }
    }
}
```

### 结论

- 最好情况：$O(n)$
- 一般情况：$O(n^2)$
- 空间复杂度：$O(1)$
- 稳定
- 适合原始序列基本有序的情况

## Shell 排序

### 核心思想

先按较大增量 $gap$ 分组，对各子序列排序；再逐步缩小 $gap$，直到 $gap = 1$。

### 课件算法

```c
void shellSort(keytype k[], int n) {
    int i, j, flag, gap = n;
    keytype temp;
    while (gap > 1) {
        gap = gap / 2;
        do {
            flag = 0;
            for (i = 0; i < n - gap; i++) {
                j = i + gap;
                if (k[i] > k[j]) {
                    temp = k[i];
                    k[i] = k[j];
                    k[j] = temp;
                    flag = 1;
                }
            }
        } while (flag != 0);
    }
}
```

### 结论

- 时间复杂度介于 $O(n\log_2 n)$ 与 $O(n^2)$ 之间
- 课件常写为通常小于 $O(n^{3/2})$
- 空间复杂度：$O(1)$
- 不稳定

## 堆排序

## 堆的定义

课件选择大顶堆：

对序列 $(k_1, k_2, ..., k_n)$，若对所有 $i = 1, 2, ..., \lfloor n/2 \rfloor$ 满足：

- $k_i \ge k_{2i}$
- $k_i \ge k_{2i+1}$

则该序列为大顶堆。

### 特点

- 堆是一棵完全二叉树
- 根结点值最大

## 调整子算法

```c
void adjust(keytype k[], int i, int n) {
    int j;
    keytype temp;
    temp = k[i];
    j = 2 * i + 1;
    while (j < n) {
        if (j + 1 < n && k[j] < k[j + 1]) j++;
        if (temp < k[j]) {
            k[(j - 1) / 2] = k[j];
            j = 2 * j + 1;
        } else break;
    }
    k[(j - 1) / 2] = temp;
}
```

## 堆排序算法

```c
void heapSort(keytype k[], int n) {
    int i;
    keytype temp;
    for (i = n / 2 - 1; i >= 0; i--) adjust(k, i, n);
    for (i = n - 1; i >= 1; i--) {
        temp = k[i];
        k[i] = k[0];
        k[0] = temp;
        adjust(k, 0, i);
    }
}
```

### 结论

- 时间复杂度：$O(n\log_2 n)$
- 空间复杂度：$O(1)$
- 不稳定

## 归并排序

### 二路归并

定义：

> 将两个位置相邻、并且各自按值有序的子序列合并为一个按值有序的子序列，这一过程称为二路归并。

### 合并算法

```c
void merge(keytype x[], keytype tmp[], int left, int leftend, int rightend) {
    int i = left, j = leftend + 1, q = left;
    while (i <= leftend && j <= rightend)
        if (x[i] <= x[j]) tmp[q++] = x[i++];
        else tmp[q++] = x[j++];
    while (i <= leftend) tmp[q++] = x[i++];
    while (j <= rightend) tmp[q++] = x[j++];
    for (i = left; i <= rightend; i++) x[i] = tmp[i];
}
```

### 主算法

```c
void mergeSort(keytype k[], int n) {
    keytype *tmp;
    tmp = (keytype *)malloc(sizeof(keytype) * n);
    if (tmp != NULL) {
        mSort(k, tmp, 0, n - 1);
        free(tmp);
    }
}

void mSort(keytype k[], keytype tmp[], int left, int right) {
    int center;
    if (left < right) {
        center = (left + right) / 2;
        mSort(k, tmp, left, center);
        mSort(k, tmp, center + 1, right);
        merge(k, tmp, left, center, right);
    }
}
```

### 结论

- 时间复杂度：$O(n\log_2 n)$
- 空间复杂度：$O(n)$
- 稳定
- 本质上是分治算法

## 快速排序

### 核心思想

选一个分界元素 `pivot`，把小于它的放左边，大于它的放右边，使其落在最终位置，再递归处理左右两部分。

### 课件算法

```c
void quick(keytype k[], int left, int right) {
    int i, j;
    keytype pivot;
    if (left < right) {
        i = left;
        j = right + 1;
        pivot = k[left];
        while (1) {
            while (k[++i] < pivot && i != right);
            while (k[--j] > pivot && j != left);
            if (i < j) swap(&k[i], &k[j]);
            else break;
        }
        swap(&k[left], &k[j]);
        quick(k, left, j - 1);
        quick(k, j + 1, right);
    }
}

void quickSort(keytype k[], int n) { quick(k, 0, n - 1); }
```

### 结论

- 最好情况：$O(n\log_2 n)$，空间 $O(\log_2 n)$
- 平均情况：$O(n\log_2 n)$，空间 $O(\log_2 n)$
- 最坏情况：$O(n^2)$，空间 $O(n)$
- 不稳定
- 本质上是分治算法

## 排序算法总比较

### 课件总结

- 简单排序：冒泡、选择、插入
- 改进排序：Shell、堆、归并、快速

从稳定性看：

- 稳定：插入、冒泡、归并
- 不稳定：选择、Shell、堆、快速

从空间复杂度看：

- 堆排序空间开销小
- 归并排序需要额外辅助数组
- 快速排序需要递归栈空间

## 本章应记住的结论

- 插入排序、冒泡排序是稳定排序。
- 选择排序、Shell 排序、堆排序、快速排序都不稳定。
- 折半插入只减少比较次数，不减少移动次数。
- 归并排序稳定且时间复杂度稳定在 $O(n\log_2 n)$，但要额外空间。
- 快速排序平均很快，但最坏会退化到 $O(n^2)$。
