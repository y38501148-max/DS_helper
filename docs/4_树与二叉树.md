# 树与二叉树

## 树

### 定义与特点

树的递归定义可概括为：

- 树是 `n≥0` 个结点的有穷集合。
- 当 $n=0$ 时为空树。
- 当 $n>0$ 时，有且仅有一个根结点，其余结点分成若干个互不相交的子集，每个子集本身又是一棵树，称为根的子树。

树的逻辑特点：

1. 有且仅有一个结点没有前驱，该结点是根结点。
2. 除根结点外，每个结点有且仅有一个直接前驱。
3. 每个结点可以有多个后继。

### 基本术语

- 结点的度：该结点拥有的子树数目。
- 树的度：树中结点度的最大值。
- 叶结点：度为 `0` 的结点。
- 分支结点：度非 `0` 的结点。
- 树的层次：根结点为第 `1` 层。
- 树的深度（高度）：树中结点所处的最大层次数。
- 路径长度：路径上的结点数减 `1`。
- 森林：`m≥0` 棵互不相交的树的集合。

## 二叉树

### 定义

> 二叉树是 `n≥0` 个结点的有穷集合 `D` 与 `D` 上关系集合 `R` 构成的结构。  
> 当 $n=0$ 时，称为空二叉树；否则，它包含一个根结点以及两棵互不相交的、分别称为左子树与右子树的二叉树。

课件特别强调：

- 二叉树是有序树。
- 左右子树有严格区分。

### 两种特殊二叉树

- 满二叉树：每个结点或者是叶结点，或者有两棵非空子树，且叶结点集中在最下面一层。
- 完全二叉树：只有最下面两层的结点度可以小于 `2`，且最下面一层叶结点依次排列在该层最左位置。

## 二叉树的重要性质

1. 具有 `n` 个结点的非空二叉树共有 `n-1` 个分支。
2. 非空二叉树第 $i$ 层最多有 $2^{i-1}$ 个结点。
3. 深度为 $h$ 的非空二叉树最多有 $2^h - 1$ 个结点。
4. 若非空二叉树有 `n0` 个叶结点、`n2` 个度为 `2` 的结点，则：

   $$
   n_0 = n_2 + 1
   $$

5. 具有 `n` 个结点的非空完全二叉树深度为：

   $$
   h = \lfloor \log_2 n \rfloor + 1
   $$

6. 对 `n` 个结点的完全二叉树按层次编号时：

- 若编号从 `1` 开始：
  - 双亲：$\lfloor i/2 \rfloor$
  - 左孩子：$2i$
  - 右孩子：$2i+1$
- 若编号从 `0` 开始（C 语言常用）：
  - 双亲：$\lfloor (i-1)/2 \rfloor$
  - 左孩子：$2i+1$
  - 右孩子：$2i+2$

## 二叉树的存储结构

### 顺序存储

适合：

- 满二叉树
- 接近满二叉树的完全二叉树

优点：

- 由双亲查子、由子查双亲都方便。

缺点：

- 对退化二叉树空间浪费大。
- 需要预先分配存储空间。

### 链式存储

二叉链表结点定义：

```c
struct node {
    Datatype data;
    struct node *left, *right;
};
typedef struct node BTNode;
typedef struct node *BTNodeptr;
```

## 二叉树遍历

### 定义

> 按照一定顺序对二叉树中每一个结点都访问一次，得到由所有结点组成的序列，这一过程称为二叉树的遍历。

### 四种遍历

- 前序：`DLR`
- 中序：`LDR`
- 后序：`LRD`
- 层次遍历

### 前序遍历

规则：

1. 访问根结点
2. 前序遍历左子树
3. 前序遍历右子树

```c
void preorder(BTNodeptr t) {
    if (t != NULL) {
        VISIT(t);
        preorder(t->left);
        preorder(t->right);
    }
}
```

### 中序遍历

规则：

1. 中序遍历左子树
2. 访问根结点
3. 中序遍历右子树

```c
void inorder(BTNodeptr t) {
    if (t != NULL) {
        inorder(t->left);
        VISIT(t);
        inorder(t->right);
    }
}
```

### 后序遍历

规则：

1. 后序遍历左子树
2. 后序遍历右子树
3. 访问根结点

```c
void postorder(BTNodeptr t) {
    if (t != NULL) {
        postorder(t->left);
        postorder(t->right);
        VISIT(t);
    }
}
```

### 层次遍历

课件采用队列实现：

```c
#define NodeNum 100

void layerorder(BTNodeptr t) {
    BTNodeptr queue[NodeNum], p;
    int front, rear;
    if (t != NULL) {
        queue[0] = t;
        front = 0;
        rear = 0;
        while (front <= rear) {
            p = queue[front++];
            VISIT(p);
            if (p->left != NULL) queue[++rear] = p->left;
            if (p->right != NULL) queue[++rear] = p->right;
        }
    }
}
```

课件结论：

- 前序、中序、后序遍历本质上是深度优先遍历（DFS）。
- 层次遍历本质上是广度优先遍历（BFS）。
- 层次遍历时间复杂度为 $O(n)$。

## 由遍历序列恢复二叉树

课件结论：

- 已知前序序列和中序序列，可以恢复二叉树。
- 已知中序序列和后序序列，也可以恢复二叉树。
- 仅由前序和后序序列，一般不能唯一恢复二叉树。

规律：

- 前序 + 中序：在前序中确定根，到中序中分左右。
- 后序 + 中序：在后序中确定根，到中序中分左右。

## 二叉树的典型操作

### 拷贝

```c
BTNodeptr copyTree(BTNodeptr src) {
    BTNodeptr obj;
    if (src == NULL) obj = NULL;
    else {
        obj = (BTNodeptr)malloc(sizeof(BTNode));
        obj->data = src->data;
        obj->left = copyTree(src->left);
        obj->right = copyTree(src->right);
    }
    return obj;
}
```

### 删除

```c
void destoryTree(BTNodeptr p) {
    if (p != NULL) {
        destoryTree(p->left);
        destoryTree(p->right);
        free(p);
        p = NULL;
    }
}
```

### 求高度

```c
int heightTree(BTNodeptr p) {
    if (p == NULL) return 0;
    else return 1 + max(heightTree(p->left), heightTree(p->right));
}
```

课件强调：

- 树拷贝对应前序思想。
- 树删除对应后序思想。

## 二叉查找树 BST

### 定义

> 二叉查找树或者为空二叉树，或者为具有以下性质的二叉树：  
> 若根结点的左子树不空，则左子树上所有结点的值都小于根结点的值；  
> 若根结点的右子树不空，则右子树上所有结点的值都大于或等于根结点的值；  
> 每一棵子树分别也是二叉查找树。

### 重要结论

- BST 的中序遍历序列是有序序列。

### 递归插入

```c
BTNodeptr insertBST(BTNodeptr p, Datatype item) {
    if (p == NULL) {
        p = (BTNodeptr)malloc(sizeof(BTNode));
        p->data = item;
        p->left = p->right = NULL;
    } else if (item < p->data) {
        p->left = insertBST(p->left, item);
    } else if (item > p->data) {
        p->right = insertBST(p->right, item);
    }
    return p;
}
```

### 查找

非递归：

```c
BTNodeptr searchBST(BTNodeptr t, Datatype key) {
    BTNodeptr p = t;
    while (p != NULL) {
        if (key == p->data) return p;
        if (key > p->data) p = p->right;
        else p = p->left;
    }
    return NULL;
}
```

递归：

```c
BTNodeptr searchBST(BTNodeptr t, Datatype key) {
    if (t != NULL) {
        if (key == t->data) return t;
        if (key > t->data) return searchBST(t->right, key);
        else return searchBST(t->left, key);
    }
    return NULL;
}
```

### 删除原则

1. 被删结点是叶结点：直接删除。
2. 无左子树：用右子树根取代。
3. 无右子树：用左子树根取代。
4. 左右子树都存在：用右子树中最小结点，或左子树中最大结点取代。

### 查找效率

- 理想情况下：$O(\log_2 n)$
- 退化为单支树时：$O(n)$

### AVL 树

课件定义：

> 平衡二叉树或者是一棵空树，或者左右子树都是平衡二叉树，且左右子树深度之差的绝对值不超过 `1`。

平衡因子只可能是：$-1, 0, 1$。

## 堆 Heap

### 定义

课件将堆定义为一种特殊类型的二叉树，满足两个性质：

1. 每个结点的值大于（或小于）等于其每个子结点的值。
2. 该树完全平衡，最后一层叶结点位于最左侧位置。

满足这两个性质的分别称为：

- 大顶堆（max heap）
- 小顶堆（min heap）

课件默认以大顶堆为主讨论。

### 基本性质

课件强调：

- 堆是一棵完全二叉树。
- 一般采用数组实现。
- 对于下标为 $i$ 的结点：
  - 父结点下标为 $\lfloor (i-1)/2 \rfloor$
  - 子结点下标为 $2i+1,\ 2i+2$

对大顶堆，有：

- $heap[i] \ge heap[2i+1]$
- $heap[i] \ge heap[2i+2]$

### 特点

课件给出的关键结论：

- 层次序列中的第一个元素，也就是二叉树根结点的值最大。
- 堆的最大好处是元素查找、插入和删除效率高，复杂度为 $O(\log_2 n)$。

### 基本操作

课件列出的两个基本操作是：

- `insert`（插入）
- `delete`（删除）

#### 插入

课件算法描述：

1. 将新元素放在堆的末尾；
2. 当该元素不是根，且其值大于父结点时，与父结点交换。

#### 删除

课件说明删除是“获取堆顶元素，并从堆中删除”，步骤为：

1. 从根结点提取元素；
2. 将最后一个叶结点中的元素放到被删除元素位置；
3. 删除最后一个叶结点；
4. 从根开始向下调整，与较大的子结点交换，直到重新满足堆性质。

### 堆的构造

课件给出两种构造方法：

- 自顶向下（John Williams）
- 自底向上（Robert Floyd）

其中：

- 自顶向下：从空堆开始，按顺序向堆中添加元素
- 自底向上：先从底层构造较小的堆，再逐步构造较大的堆

### 典型应用

课件列出的主要应用：

1. 优先队列（Priority Queue）
2. 堆排序（Heap Sort）

其中课件给出的复杂度结论是：

- 优先队列用堆实现时，元素管理效率高，为 $O(\log_2 N)$
- 堆排序是一种高效排序算法，复杂度为 $O(n\log_2 n)$

## 表达式树 Expression Tree

### 定义

课件将表达式树定义为一种特殊类型的树：

- 叶结点是操作数（operand）
- 其他结点是操作符（operator）

进一步说明：

1. 由于操作符一般是双目的，通常表达式树是一棵二叉树。
2. 对于单目操作符（如 `++`），其只有一个子结点。

### 最大好处

课件原意很明确：

> 表达式树的最大好处是表达式没有括号，计算时也不用考虑运算符优先级。

主要应用：

- 编译器用来处理程序中的表达式

### 遍历与表达式形式

课件用表达式

$$
a + b * (c - d) - e / f
$$

说明表达式树与遍历的关系：

- 中序遍历得到中缀表达式
- 后序遍历得到后缀表达式

课件给出的后缀表达式形式为：

$$
a\ b\ c\ d\ -\ *\ +\ e\ f\ /\ -
$$

### 构造方法

课件给出的是“由后缀表达式生成表达式树”的方法。

核心思想：

> 表达式树是这样一种树，非叶结点为操作符，叶结点为操作数，对其进行遍历可计算表达式的值。

构造步骤：

1. 从左至右读入后缀表达式中的一个符号。
2. 如果是操作数：
   - 建立一个单结点树；
   - 将该结点指针压入栈中。
3. 如果是运算符：
   - 从栈中弹出指向两棵树 $T_1$ 和 $T_2$ 的指针，其中 $T_1$ 先弹出；
   - 建立一棵新树，根结点为该运算符；
   - 左子树指向 $T_2$，右子树指向 $T_1$；
   - 将新树根指针重新压栈。
4. 重复上述过程，直到后缀表达式处理完。

课件示例后缀表达式为：

$$
ab+cde+**
$$

## 哈夫曼树 Huffman Tree

### 带权路径长度

课件先定义了树的带权路径长度。

若一棵具有 $m$ 个叶结点的二叉树，每个叶结点赋予一个权值，则该二叉树的带权路径长度定义为：

$$
WPL = \sum_{i=1}^{m} w_i l_i
$$

其中：

- $w_i$ 为第 $i$ 个叶结点的权值
- $l_i$ 为第 $i$ 个叶结点的路径长度

### 定义

> 给定一组权值，构造出的具有最小带权路径长度的二叉树称为哈夫曼树。

### 特点

课件列出三条关键性质：

1. 权值越大的叶结点离根越近，权值越小的叶结点离根越远。
2. 无度为 $1$ 的结点。
3. 哈夫曼树不是唯一的。

### 构造思想

课件给出的核心思想如下：

1. 对于给定权值集合 $W=\{w_1,w_2,\ldots,w_m\}$，先构造一个森林
   $$
   F=\{T_1,T_2,\ldots,T_m\}
   $$
   其中每棵树只有一个根结点，该根同时也是叶结点，其权值为对应的 $w_i$。
2. 从森林中选出根权值最小的两棵二叉树，将它们合并成一棵新的二叉树：
   - 这两棵树分别作为新树的左、右子树；
   - 新根结点权值等于这两棵树根权值之和。
3. 将新树加入森林，同时删除原来那两棵树。
4. 重复上述过程，直到森林中只剩下一棵二叉树。

课件示例权值集合：

$$
W=\{7,5,2,4\}
$$

### 哈夫曼编码

课件进一步把哈夫曼树用于二进制前缀编码。

约定：

- 左分支表示字符 `0`
- 右分支表示字符 `1`
- 从根到叶结点路径上的分支字符组成该字符编码

课件强调：

- 任意一个字符的编码不能是另一个字符编码的前缀
- 出现频率大的字符应使用较短编码

设电文中包含 $n$ 种字符，$w_i$ 为第 $i$ 种字符出现次数，$l_i$ 为对应编码长度，则电文总长度为：

$$
\sum_{i=1}^{n} w_i l_i
$$

这与哈夫曼树的带权路径长度最小完全对应。

### 文件压缩中的使用流程

课件在“文件压缩”问题里给出 Huffman 编码的整体流程：

1. 对源文件进行字符频率统计；
2. 根据频率统计结果生成 Huffman 树；
3. 遍历 Huffman 树生成每个字符的 Huffman 编码；
4. 按新编码将源文件每个字符转换并输出到目标文件。

### 课件中的数据结构设计

```c
#define MAXSIZE 32

struct cc {
    char c;
    int count;
};

struct tnode {
    struct cc ccount;
    struct tnode *left, *right;
    struct tnode *next;
};

struct tnode *Head = NULL;
char Huffman[MAXSIZE];
char HCode[128][MAXSIZE];
```

### 课件中的关键代码

字符频率统计：

```c
struct cc ccount[128];

while ((c = fgetc(fp)) != EOF) {
    ccount[c].c = c;
    ccount[c].count++;
}
```

由字符统计结果构造有序链表：

```c
struct tnode *p;
for (i = 0; i < 128; i++) {
    if (ccount[i].count != 0) {
        p = (struct tnode *)malloc(sizeof(struct tnode));
        p->ccount = ccount[i];
        p->left = p->right = p->next = NULL;
        insertSortLink(p);
    }
}
```

由有序表构造 Huffman 树：

```c
while (Head->next != NULL) {
    p = (struct tnode *)malloc(sizeof(struct tnode));
    p->ccount.count = Head->ccount.count + Head->next->ccount.count;
    p->left = Head;
    p->right = Head->next;
    p->next = NULL;
    Head = Head->next->next;
    insertSortLink(p);
}
```

遍历 Huffman 树生成编码：

```c
void createHCode(struct tnode *p, char code, int level) {
    if (level != 0) Huffman[level - 1] = code;
    if (p->left == NULL && p->right == NULL) {
        Huffman[level] = '\0';
        strcpy(HCode[p->ccount.c], Huffman);
    } else {
        createHCode(p->left, '0', level + 1);
        createHCode(p->right, '1', level + 1);
    }
}
```

## 本章应记住的结论

- 二叉树不是“度为 2 的树”，关键在于左右子树有序。
- 完全二叉树的顺序存储公式必须熟记。
- 前中后序是 DFS，层次遍历是 BFS。
- BST 的中序序列一定有序。
- BST 的效率取决于树形态，不平衡时会退化。
- 堆是完全二叉树，适合优先队列与堆排序。
- 表达式树通常由后缀表达式借助栈来构造。
- 哈夫曼树的核心目标是最小带权路径长度，哈夫曼编码本质上建立在这一点上。
