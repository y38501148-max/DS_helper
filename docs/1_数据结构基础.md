# 数据结构基础

## 递归

### 定义

> 通过调用自身解决问题的过程称为递归。

课件补充：在 C 语言中，一个函数直接或间接调用自己称为递归。

### 递归示例：求 `n!`

```c
#include <stdio.h>

int fact(int n);

main() { printf("3!=%d, 5!=%d\n", fact(3), fact(5)); }

int fact(int n) {
    if (n <= 1) return 1;
    else return n * fact(n - 1);
}
```

对应的非递归写法：

```c
int fact(int n) {
    int f;
    for (f = 1; n > 0; n--) f *= n;
    return f;
}
```

### 递归使用规则

- 基本实例（base case）：问题的解包含一个或多个可以直接求解的基本实例。
- 递进（making progress）：递归调用必须朝着基本实例推进。

课件给出的典型表达：

- $0! = 1$
- $n! = n \times (n - 1)!$

## 数组与字符数组

### 数组初始化

课件中的典型写法：

```c
double sales[5] = {12.25, 32.50, 16.90, 23, 45.68};
double sales[] = {12.25, 32.50, 16.90, 23, 45.68};
int list[5] = {6, 5, 12}; /* 相当于 {6,5,12,0,0} */
int list[5] = {0};        /* 最常用的全 0 初始化 */
char string[10] = "hello";
char string[10] = {'h', 'e', 'l', 'l', 'o', '\0'};
char string[] = "hello";
```

### 需要记住的结论

- 长度为 `N` 的数组，下标范围是 `0 ~ N-1`。
- 用字符串常量初始化字符数组时，数组长度至少要比字符个数多 `1`。
- 字符串以 `'\0'` 结束。

### 数组作为函数参数

课件结论：

> 实际上传递的是数组的首地址。  
> 形参数组与实参数组是一对共享同一数据区的数组，即它们是同一个数组，而不是对实参数组的拷贝。

非字符数组参数形式：

```c
void fun(int array[], int size) { ... }
```

注意：

- 定义数组形参时，数组长度可省略。
- 对于非字符数组，通常还应显式传元素个数。
- 字符数组常因 `'\0'` 结束而不必额外传长度。

## 字符串处理

### 数字串转整数 `atoi`

```c
int atoi(char s[]) {
    int i, n, sign;
    for (i = 0; s[i] == ' ' || s[i] == '\n' || s[i] == '\t'; i++)
        ; /* skip white space */
    sign = 1;
    if (s[i] == '+' || s[i] == '-') sign = (s[i++] == '+') ? 1 : -1;
    for (n = 0; s[i] >= '0' && s[i] <= '9'; i++) n = 10 * n + s[i] - '0';
    return sign * n;
}
```

### 字符串逆置 `reverse`

```c
void reverse(char s[]) {
    int c, i, j;
    for (i = 0, j = strlen(s) - 1; i < j; i++, j--) {
        c = s[i];
        s[i] = s[j];
        s[j] = c;
    }
}
```

课件还给出 `strlen` 的实现：

```c
int strlen(char s[]) {
    int i = 0;
    while (s[i] != '\0') ++i;
    return i;
}
```

### 整数转字符串 `itoa`

```c
void itoa(int n, char s[]) {
    int i, sign;
    if ((sign = n) < 0) n = -n;
    i = 0;
    do {
        s[i++] = n % 10 + '0';
    } while ((n /= 10) > 0);
    if (sign < 0) s[i++] = '-';
    s[i] = '\0';
    reverse(s);
}
```

## 文本查找

### 朴素字符串查找算法

课件要求掌握的核心函数：

```c
int index(char s[], char t[]) {
    int i, j, k;
    for (i = 0; s[i] != '\0'; i++) {
        for (j = i, k = 0; t[k] != '\0' && s[j] == t[k]; j++, k++);
        if (t[k] == '\0') return i;
    }
    return -1;
}
```

### 查文件中包含给定字符串的行

```c
#include <stdio.h>
#define MAXLINE 1024

int index(char s[], char t[]);

int main() {
    char filename[64], s[81], line[MAXLINE];
    FILE *fp;

    scanf("%s", filename);
    scanf("%s", s);

    if ((fp = fopen(filename, "r")) == NULL) {
        printf("Can't open file %s!\n", filename);
        return 1;
    }

    while (fgets(line, MAXLINE - 1, fp) != NULL) {
        if (index(line, s) >= 0) printf("%s", line);
    }
    return 0;
}
```

### 复杂度

课件结论：

- 朴素字符串查找算法时间复杂度为 $O(nm)$。
- 最坏情况下，执行频度为 $N\times M$。
  - `N` 为源串长度。
  - `M` 为目标串长度。

## 预处理与字符转换

### 宏函数

```c
#define max(A, B) ((A) > (B) ? (A) : (B))
#define tolower(c) (c >= 'A' && c <= 'Z' ? 'a' - 'A' + c : c)
```

需要记住：

- 宏定义名与参数之间不能有空格。
- 参数最好加括号。

### `tolower` 函数写法

```c
char tolower(char c) {
    if (c >= 'A' && c <= 'Z') return 'a' - 'A' + c;
    return c;
}
```

## 结构与 `typedef`

### 结构定义

> 结构是由若干分量组成的一种构造类型。组成结构的各个分量可以具有不同的类型，对结构变量的访问必须通过分量名进行。

结构模板形式：

```c
struct date {
    int day;
    int month;
    int year;
    int yearday;
    char mon_name[4];
};
```

### `typedef`

课件强调：

> `typedef` 不产生新的数据类型，也不定义存储单元，只是给已有类型增加一个新的类型名。

常见写法：

```c
typedef int LENGTH;
typedef char *STRING;
```

链表结点类型定义：

```c
typedef struct node {
    int n;
    struct node *next;
} *Nodeptr;
```

## 本章应记住的结论

- 递归必须有基本实例，且递归调用必须朝着基本实例推进。
- 数组作参数时，本质上传的是首地址。
- 字符串处理的关键约定是以 `'\0'` 结束。
- 朴素字符串查找的时间复杂度是 $O(nm)$。
- `typedef` 是“起别名”，不是“造新类型”。
